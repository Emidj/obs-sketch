# Example provenance

The original fictional pilot character was created with the built-in image generation tool. Prompt: "Photorealistic original adult female sci-fi pilot, short curly dark hair, teal and burnt orange utilitarian jacket, neutral gray studio background, soft directional lighting, no logos, no text, no drawing effect; unfiltered input for an OBS Sketch demonstration."

The input was resized to 960 x 720 and passed through the unchanged official OBS Sketch 1.5 DLL using the project's gpu-test harness and OBS 32.2.2 libobs / Direct3D 11 on NVIDIA GeForce RTX 5070. The four mode buffers were arranged in two labelled JPEG comparison sheets. Filtered pixels were not generated or retouched to simulate the plugin. All controls were those used by the existing four-finish regression test; only the finish changes between those four outputs.

The publication added English documentation and demonstration images. Plugin sources and official installer / portable binaries were not modified.
